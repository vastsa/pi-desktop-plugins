Parchment Theme / 羊皮纸主题

This plugin contributes one global theme and nothing else. 本插件只贡献一个全局主题，无其他功能。

  • Apply: Settings → Theme → search Parchment
  • 应用：设置 → 主题 → 搜索 Parchment
  • Revert: pick Light / Dark / System 切回浅色 / 深色 / 系统

Theme file: themes/parchment.css (edit it, then reload the plugin).

主题文件：themes/parchment.css（修改后重载插件生效）。
