# 草稿计算器

PI-Desktop 插件：一个极简的草稿计算器面板，黄白书本暖色调。

## 交互

- **回车计算**：输入公式按 Enter 立即计算，结果**保留在输入框**中，可直接继续链式计算（如 `1+2` 回车得 `3`，再输入 `*4` 回车得 `12`）；
- **历史栈**：每次有效计算自动入栈，**最新一条永远置顶**，旧条目依次下推；历史卡片只有一行「公式 = 结果」，点击可回填公式继续修改；
- **纯数字不记录**：输入框里只是自由数字（如 `5`、`-3`、`3.14`）时按回车不写入历史，只做轻微边框提示；
- **Esc 清空**，**Backspace 退格**；
- **↑ / ↓ 浏览历史**：↑ 从最新逐条往更旧回填，↓ 返回并最终清空输入框，开始编辑自动退出浏览态；
- **尾部运算符容错**：公式结尾多余的计算符号自动忽略并记录干净公式（`10+88+` 回车得 `98`，历史记为 `10+88 = 98`）；非运算字符（字母、@ 等）仍会报错；
- **中文输入法友好**：选词回车不会误触发计算；全角数字/符号（３＋４、２．５）自动归一化；
- 历史保存在 localStorage（上限 200 条），面板重开仍在；出错时输入框轻微抖动、不清空、不记录。

## 支持的公式语法

- 四则运算：`+ - * /`，兼容全角 `＋ － × ÷（ ）` 与全角数字、小数点；
- 括号任意嵌套；乘方 `^` 右结合（`2^3^2 = 512`），`^2` 即平方，支持负指数，`**` 亦可；
- 一元正负号：`-3`、`3*-2`、`-(2+3)`（`-2^2 = -4`）；
- 隐式乘法：`2(3+1)`、`2π`、`(2)(3)`；常量 `π`、`e`；
- 小数与科学计数法：`0.1+0.2 = 0.3`，超大/超小结果自动用 `e` 记数。

## 界面

- 无按钮、无文案，只有输入卡片 + 可滚动历史；
- 输入卡片与单条历史卡片同尺寸（72px），大号衬线数字（Georgia 等）右对齐；
- 纸白/暖黄配色，书本质感。

## 开发

1. 打开 Plugins 页面，用 **Load development plugin** 指向本目录，保存文件后插件自动重载；
2. 命令面板执行「草稿计算器：打开面板」；
3. 校验与打包：

```bash
pnpm pi-plugin check .
pnpm pi-plugin pack .
# 写入 dist/local.scratch-calc-0.0.1.piplug
```

## 实现说明

- 求值器为手写 tokenizer + 递归下降解析器，内嵌于 `renderer/index.html`，无第三方依赖；
- 求值器核心已单独测试（59 个用例：优先级、右结合、一元号、全角容错、错误输入）。
