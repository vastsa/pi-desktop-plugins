# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository purpose

Official **plugin source** and **GitHub raw fallback mirror** for PI-Desktop.

The live marketplace is `https://plugins.aiuo.net` (`pi-backend`). This repo is no longer the publish endpoint. CI (`scripts/sync_catalog.py`) pulls `catalog.json` and `.piplug` artifacts hourly; a failed fetch does **not** overwrite the last good mirror. Mirrored catalog URLs are relative `packages/<id>-<version>.piplug` with `artifactBaseUrl` stripped so a client that loaded GitHub raw never follows downloads back to a down origin.

`catalog.json` is generated by the mirror job — never hand-edit it for a release.

## Commands

No package.json at repo root. Tooling is Python 3 (stdlib) and Node.js (built-in test runner).

- **Pack a plugin**: `python3 scripts/pack_plugin.py plugins/<id>` — writes `packages/<id>-<version>.piplug` for local install. Publishing goes to plugins.aiuo.net, not this file tree.
- **Mirror catalog**: `python3 scripts/sync_catalog.py [--source URL] [--dry-run]`
- **Mirror unit tests**: `python3 -m unittest tests/test_sync_catalog.py`
- **Plugin tests**: `node --test tests/`, or a single file e.g. `node --test tests/gitlens.test.mjs`
- **Local catalog fixture only**: `python3 scripts/rebuild_catalog.py` — do not use this to publish
- **Local verification** in PI-Desktop: **Plugins → Load dev plugin** → `plugins/<id>`

Official plugin release flow: bump `manifest.json` version → tests → load as dev plugin → `pi-plugin publish --registry https://plugins.aiuo.net`. Commit messages stay conventional with the plugin id as scope.

## Architecture

### Plugin anatomy — `plugins/<id>/`

- `manifest.json` (required)
- `main.js` (required) — CommonJS, global `pi` runtime
- `renderer/` (optional)
- `skills/` (optional)
- `README.md`

Plugins are fully self-contained. Packing constraints: root `manifest.json`, no symlinks, no path traversal, max 50MB.

### Manifest essentials

- `ui.title` must be bilingual `{"en": ..., "zh-CN": ...}`. Open panels with `pi.ui.openPanel()` and no `title` option.
- Request the minimum permission set. High-risk grants force review; auto-update never silently expands them.
- Agent tools use prefix `plugin_<id_safe>_<tool>`.

### Appearance adapter — `plugins/shared/appearance/`

Copy into each plugin `renderer/`. Not shipped as a shared runtime. Panel chrome: 46px host drag band, `top: var(--pi-plugin-titlebar-height, 46px)` for window-level fixed UI.

### Packages & catalog

- Production `catalog.json` / `packages/*.piplug` come from `scripts/sync_catalog.py`.
- Rewrite rule: drop `artifactBaseUrl`, set each version `url` to `packages/<id>-<version>.piplug`, verify sha256. Yanked versions are not re-downloaded (410); keep a local file if the hash still matches.
- Empty catalogs and hash mismatches abort the sync.

### Tests

`tests/*.test.mjs` use `node:test`. `tests/test_sync_catalog.py` covers rewrite, empty-catalog reject, HTTP sync, and fail-closed overwrite.
